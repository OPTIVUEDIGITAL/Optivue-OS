# Growth OS copy editing rules

Owner instructions, 23 September 2026. Apply to copy after the approved repositioning to health, wellness and aesthetics. The earlier chiropractic-only homepage is pending owner review.

1. Use present tense and active voice.
2. Remove adverbs ending in -ly unless removal changes meaning.
3. Keep sentences below 20 words, with most below 12.
4. Aim for grade 5–7. Report before-and-after readability per section with the scoring method and exceptions. Do not add filler to raise an easier score.
5. Remove words and sentences which add no meaning.
6. Name problems briefly. Spend most words on outcomes.
7. Limit not-X-but-Y to one construction per page, slip-away wording to one site-wide use, and em dashes to two per page.
8. Preserve prices, offer names, legal/disclaimer text and every [CONFIRM] placeholder. Protected text overrides other copy rules.
9. Report every proposed edit as before → after.
10. Hero changes require options and owner selection. Never auto-apply them.

No merge or deployment without owner approval. A copy proposal does not approve the earlier positioning changes.
