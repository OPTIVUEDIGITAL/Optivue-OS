# Client evidence permission request

Use this only for artefacts already produced during the client engagement.

## Short request

> Hi [Name] — I’m updating my professional portfolio and would like permission to show a small, anonymised example of work I completed for [Company]. I would remove personal/client-identifying data, confidential values, and anything sensitive. The purpose is only to demonstrate the structure of the work (for example, a workflow, dashboard, portal, or campaign setup), not to disclose internal information or make new performance claims.
>
> Are you comfortable with me using an anonymised screenshot or labelled reconstruction of that work in my portfolio?
>
> If yes, I’ll keep the company/client context accurate and remove anything you identify as confidential.

## Recording the decision

For each artefact record:

- client
- artefact description
- date permission was requested
- written response
- whether the client approved: original screenshot / anonymised screenshot / labelled reconstruction / no use
- specific redactions or restrictions
- source of the written permission

Do not convert silence into permission.
