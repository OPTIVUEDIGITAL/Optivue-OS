- Lock design tokens and typography.

- Implement the cinematic hero with SVG/CSS/JS, not a framework dependency.
- Implement the shared booking modal.

## Phase 2 — Product story
- Build Growth System visualizer.
- Add Transformations and Work Lab structures.

- Build five-step Growth Diagnosis.

## Phase 4 — Integrations
- Connect audit submissions to approved CRM / Make / data destination.
- Add analytics events through GA4/GTM.
- Add optional backend endpoints only when required.

## Phase 5 — QA and launch
- Accessibility review (WCAG AA target).
- Reduced-motion validation.
- Cross-browser and Wix/embed testing.
- Performance optimization.
- SEO metadata and structured content review.
- Deployment and domain connection.
