## Shared design system

All Stitch archives included the same DESIGN.md.

Canonical implementation principles:
- dark baseline: #090A0C
- primary surface: #111317
- secondary surface: #171A20
- elevated surface: #1D2027
- primary text: #F5F7FA
- secondary text: #9CA3AF
- Optivue blue: #4C8DFF
- growth green: #34D399
- data violet: #8B83FF
- Inter for narrative/UI
- JetBrains Mono for telemetry/system labels
- 4/8-point spacing rhythm
- restrained borders, minimal shadows
- no decorative neon or heavy glassmorphism

## Production content integrity

Never publish generated claims from the visual references unless verified.

This includes:
- fabricated client names
- fabricated performance metrics
- fabricated live-capacity messages
- fabricated compliance claims
- fabricated uptime / latency / attribution figures
- generated testimonials or quotations

Where no verified number exists, describe the operational transformation instead.
